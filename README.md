## 기능 명세서

손님용

- 매장 정보 페이지: 매장 이름, 영업·접수 여부, 현재 대기 팀 수
- 웨이팅 등록 페이지: 이름, 전화번호, 인원수 입력 → 번호표 발급
- 내 웨이팅 상태 보기: 번호표 번호, 상태, 앞 대기 팀 수
- 웨이팅 취소: 대기 중이거나 호출된 상태에서 가능

관리자용

- 매장 CRUD: 매장 등록, 조회, 수정, 삭제
- 접수 시작·종료: 시작 시 번호표 1번부터, 종료 시 남은 대기 일괄 취소
- 내 매장 웨이팅 목록: 대기 중·호출된 웨이팅을 번호순으로 표시
- 웨이팅 처리: 목록에서 호출, 입장, 취소

나중에 추가할 기능

- 직원 로그인
- SSE 자동 갱신 (손님 화면, 관리자 화면)
- PWA 호출 알림
